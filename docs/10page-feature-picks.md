# 10PAGE 관리자에서 가져올 기능 (참고용 정리)

2026-10-02, 10PAGE 관리자(PHP)를 화면만 둘러보고 정리했다. 똑같이 만들지 않는다.
우리 웹빌더(Node.js, JSON 기반 노코드)에 맞는 기능과 편의성만 고른다.
범위: 대시보드, 메인, 페이지, 사이트 설정, CSS 스타일시트, 파일 관리자 (+ 메뉴는 확인 중)

표시: ★ 꼭 가져오기 · ○ 있으면 좋음 · ✕ 가져오지 않음

## 1. 대시보드

## 8. 공통으로 가져올 편의성

- **변경 이력(최근 10건) + 되돌리기**: 저장할 때마다 이전 내용을 보관 (페이지, CSS, 사이트 설정)
- **홈페이지 수정 로그**: 누가 언제 무엇을 바꿨는지 (homepage_log 같은 표)
- **위험 입력 차단 안내**: 스크립트 칸에 넣을 수 있는 것과 없는 것 안내문
- **각 화면 아래 짧은 도움말**: 10PAGE 처럼 화면마다 주의사항을 짧게

## 9-1. 하드코딩 HTML (2026-10-02 결정 대기)

고객이 쓰는 노코드 빌더지만, 우리(제작사)가 직접 고쳐 줄 수 있어야 한다.

- **HTML 섹션**: 섹션 하나를 HTML + CSS(+JS) 코드로 채운다. 다른 섹션과 섞어 쓴다. 고객 화면에서는 잠긴 블록으로 보이고 글자만 바꿀 수 있게 하는 것도 가능
- **HTML 페이지**: 페이지 전체를 코드로 만든다 (10PAGE 페이지 관리 v1 처럼)
- **권한**: 코드 편집은 제작자 계정만. 고객 관리자는 노코드 편집만 (스크립트 넣기로 인한 사고 방지)
- **공통**: 코드 편집기(줄 번호, 찾기/바꾸기, Ctrl+S), 변경 이력 10건 되돌리기, 저장 전 미리보기
- JSON 이 원본이라는 원칙은 그대로: HTML 은 블록의 props 에 문자열로 저장한다

## 9. 추천 순서

1. 사이트 설정 확장 (로고/파비콘/OG 파일 선택, SEO, 스크립트, robots, sitemap) + 추가 CSS
2. 파일 관리자 확장 (폴더, 이름 바꾸기, 휴지통, 같은 이름 처리, 용량)
3. 메뉴 트리 + 빠른 생성
4. 대시보드 숫자 카드 (방문자, 용량, 페이지)
5. 팝업
6. 슬라이드는 로드맵 B단계 슬라이더 요소와 함께
7. 변경 이력은 1~3을 만들 때 같이 넣기

모든 서버 기능은 Express(backend/)와 PHP(php-api/) 양쪽에 같이 만든다.
