# 웹빌더를 피그마 디자인 수준으로: 기능 차이와 단계별 계획

기준 디자인: Figma `KACDP · Renewal R-1 · Main` (file `5fRjBsezlCVvb9iEa9Nwc2`, node `859:2`)
목표: 이 화면을 웹빌더의 기본 요소(섹션 > 컨테이너 > 영역 > 텍스트/이미지/버튼…)만으로, 코드 없이 똑같이 만들 수 있게 한다.

## 1. 지금 웹빌더로 되는 것

- 섹션 > 컨테이너 > 영역(div) 중첩, 텍스트/이미지/버튼
- 배치: flex(세로/가로, 한 줄 유지, 640px 미만 쌓기), grid(`1fr 2fr`), 비율 나누기, 간격
- 여러 개 선택 + 그룹 묶기/풀기, 끌어서 순서 변경과 다른 컨테이너로 이동
- 실행 취소, 수동 저장, 파일관리자(이미지 더블클릭/끌어다 놓기)

## 2. KACDP 메인을 만들려면 모자란 것

| KACDP 화면 | 필요한 기능 | 피그마의 같은 기능 |
| --- | --- | --- |
| 바로가기 타일(회색 카드, 둥근 모서리) | 영역의 배경색, 테두리, 모서리, 안쪽 여백(상하좌우) | Fill, Stroke, Corner radius, Padding |
| 사진 타일(이미지 + 어두운 그라데이션 + 글자) | 영역 배경 이미지(cover, 위치), 그라데이션 덮개 | Image fill, Gradient fill |
| CONTACT US 타일 위 굵은 선 | 한쪽 테두리(위만) | Individual strokes |
| 카드 그림자, 버튼 둥글기 | 그림자, 투명도 | Drop shadow, Opacity |
| 타일 아이콘(56px 원) | 아이콘 요소 (lucide 아이콘 + 배경 원) | Icon component |
| "view more →", 메뉴 링크 | 글자/영역에 링크 | Prototype link |
| 히어로 슬라이드(7장, 화살표, 진행 막대) | 슬라이더 요소 | Carousel (프로토타입) |
| 헤더 9개 메뉴, 유틸 바(로그인/회원가입) | 메뉴 = 영역 + 링크 글자, 또는 페이지 목록 연결 | Auto layout + links |
| 고정 크기 이미지(560×600) | 크기 방식: 내용 맞춤 / 채우기 / 고정(px, %) / 최소·최대 | Hug / Fill / Fixed |
| 글자 스타일 | 글꼴, 자간, 대문자, 줄 수 제한 | Text properties |

## 3. 피그마처럼 "편하게" 만들기 위한 편집 기능

- 레이어 패널: 트리로 보기, 이름 바꾸기, 숨기기/잠그기, 끌어서 순서 변경
- 단축키: 복사/붙여넣기(Ctrl+C/V), 복제(Ctrl+D), 삭제(Delete), 방향키로 이동
- 정렬 도구: 왼쪽/가운데/오른쪽 맞춤, 균등 분배
- 색상 스타일, 글자 스타일 (한 번 정해 여러 곳에 쓰기)
- 컴포넌트: 그룹을 저장해 여러 번 쓰기 (타일, 카드)
- 자유 배치(절대 위치) + 제약(왼쪽/오른쪽 고정), 겹침 순서
- 화면 크기별(데스크톱/태블릿/모바일) 따로 고치기

## 4. 단계별 계획 (추천 순서)

1. **A. 스타일 속성** (KACDP의 대부분이 여기서 해결) — ✅ 완료 (2026-10-02, `src/blocks/elements/elementStyle.ts`)
   배경(색/그라데이션/이미지), 테두리(면별), 모서리, 그림자, 투명도, 안쪽 여백 상하좌우, 크기 방식(맞춤/채우기/고정), 글자 속성 확장
2. **B. 요소 추가**: 아이콘, 링크(글자·영역), 슬라이더
3. **C. 편집 UX**: 레이어 패널, 복사/붙여넣기/복제/삭제/방향키, 정렬 도구
4. **D. 재사용**: 색상·글자 스타일, 컴포넌트
5. **E. 자유 배치와 반응형**: 절대 위치 + 제약, 화면 크기별 수정

A와 B까지 끝나면 KACDP 메인을 웹빌더로 똑같이 만들 수 있다. C부터는 만드는 속도와 편의성이다.

덤: 피그마 연결(MCP)이 되어 있으니, 피그마 프레임을 읽어 웹빌더 JSON으로 바꿔 넣는 "피그마 가져오기"도 A·B 이후에 가능하다.

## 4-1. A단계 결과 (2026-10-02)

- 모든 기본 요소에 채우기(단색, 선형 그라데이션, 이미지 + 색/그라데이션 덮개), 테두리(면별), 모서리(모서리별), 그림자 1개, 투명도, 넘침 숨기기, 안쪽 여백 4면, 바깥 여백 위/아래, 크기 방식(채우기/내용 맞춤/고정, 최소·최대), 글자(글꼴, 자간, 대소문자, 밑줄/가운데 줄, 기울임, 줄 수 제한)
- 속성 패널은 내용 / 글자 / 레이아웃 / 크기 / 채우기 / 테두리 / 효과 묶음으로 접고 펼친다
- 새 속성은 모두 선택값이라 기존 데이터는 그대로 그려진다 (`tests/element-style.test.ts`)
- 남은 것: 그림자 여러 개, 방사형 그라데이션, 글꼴 직접 입력, HTML 내보내기의 기본 요소 출력

## 5. 진행 방식 (한도 절약)

- 단계마다 새 스레드에서 진행하고, 끝나면 "작업 마무리"로 GitHub에 올린다.
- 인계 정보는 기억 파일 `webbuilder-state` 와 이 문서, `docs/hybrid-elements.md` 에 있다.
- 기존 원칙 유지: 프리셋 블록 호환, 실행 취소, 수동 저장, Express와 PHP API 동기화.
